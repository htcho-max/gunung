# 군웅할거

코에이 「삼국지」 4·5편을 떠올리며 만든 삼국 시대 턴제 전략 게임입니다.
HTML 한 파일로 돌아가고, 지도·초상화·아이콘·효과음·배경 음악까지 모두 코드로 그립니다. 설치 없이 PC·태블릿·휴대폰 브라우저에서 할 수 있고, 저장은 브라우저에 됩니다.

**바로 하기:** `docs/index.html`(또는 `dist/index.html`)을 브라우저로 여세요.

## 무엇을 할 수 있나

- **시나리오 7개** — 190 반동탁 연합 · 195 군웅할거 · 200 관도대전 · 208 적벽대전 · 219 한중왕과 형주 · 221 삼국 정립 · 234 오장원
- **누구로든** — 군주, 태수, 장수(행동력 3), 재야 무장, 직접 만든 신무장. 사관·하야·방랑·거병·독립
- **내정** — 개간·상업·치안·성벽, 징병·훈련, 먼 성으로 여러 달 걸리는 이동·수송
- **인사** — 탐색·등용·포상(군주는 세력 전체), 충성과 배신, 포로 등용·석방·처단
- **외교·계략** — 친선, 기한 있는 동맹, 혼인 동맹, 이간
- **조정** — 천자(헌제)를 모시면 칙명으로 적을 역적으로, 공·왕·황제 칭호(선양), 관직 12가지(군사·대장군·승상…), 세력 고유 정책(둔전제·인덕·서량 철기·강동 수군…)
- **세상** — 강족·오환·남만·산월의 침입(회유·토벌), 역병·메뚜기·큰물, 호로관·동관·양평관·검각의 관문 전투
- **연의 / 정사** — 소설처럼 화려하게, 또는 역사서처럼 기록에 가깝게(능력치·일기토 빈도·연의만의 장면)
- **헥스 전투** — 보병·기병·궁병·노병, 진형 5가지, 둘러싸 치기, 일기토 연출, 이웃 성의 협공(최대 10부대)과 원군, 본성 점령, 30일·군량 제한
- **공성전** — 성벽과 성문 세 곳, 성벽 위 수비군의 화살·돌, 공성 병기 충차(성문 부수기)·투석(2~4칸 밖에서 성벽과 적 주변)·정란(성벽 위 적을 내려다보고 쏨), 수비군의 성벽 수리
- **지략가** — 싸움 전 군사의 계책(야습·유언비어·양도 차단·매복·내응·견벽청야·수성 준비), 싸움 중 화계·혼란·위보·고무, 지력 85↑는 사거리 3칸, 곁의 아군을 지켜 주는 간파, 지력으로 진형 펴기
- **적벽 수전** — 연환계·고육계·동남풍
- **역사 흐름** — 역사 사건 49개(도원결의 ~ 적벽 ~ 이릉 ~ 오장원 ~ 진의 통일), 세력권·숙원·후계자로 역사에 가깝게 흘러감('자유롭게'도 고를 수 있음)
- **인물** — 역사 인물 189명의 열전, 특기 16종, 명마·명검·병법서 보물 19점, 의형제, 술집, 군주의 임무, 세월이 흐르면 나타나는 새 인재
- **역사와 비교** — 연표에서 실제 역사와 내 천하를 나란히 보고 일치율 확인, 해마다 「역사에서는 이 해에…」 기록
- **업적 22가지** — 도원결의·적벽 승리·출사표·천하 통일(정사/유씨) 등, 브라우저에 영구 보관
- **인물 관계·고유 대사** — 관우와 조조, 여포와 동탁, 마초와 조조 같은 은혜·원한이 등용·전투에 영향, 인물별 출진 대사와 일기토 맞대사
- **역사적 엔딩** — 누가 어떻게 통일했는지(유씨 부흥·조씨 천하·사마씨·손씨 등)에 따라 다른 결말
- **튜토리얼** — 처음 화면의 「튜토리얼」에서 유비로 첫 싸움까지 안내
- 난이도 3단계, 매달 자동 저장 + 저장 칸 3개, 연표·인물 사전

## 구조

```
src/index.html      화면 틀과 CSS (<!--JS--> 자리에 스크립트가 들어감)
src/js/*.js         게임 코드 — 파일 이름 순서대로 이어 붙여 하나의 스크립트가 됨
  00-util, 00b-icons          공용 도구, 아이콘
  01-data, 01b-bios, 01c-traits, 01d-scen   지도·인물·열전·특기·보물·시나리오
  02-state, 04-rules, 05-war  게임 상태, 내정·인사 규칙, 출진·점령
  06-ai, 06b-history          컴퓨터 세력, 역사 흐름 장치
  07-battle                   헥스 전투 엔진 (화면 없이도 돎)
  07b-siege                   공성전(성벽·성문·공성 병기·수리)과 군사의 계책
  08-month, 08b/08c-events    달 넘김, 역사 사건
  09-ui, 09b-life             본 화면, 장수의 삶(술집·의형제·혼인·임무)
  10-map, 11-battle-ui        지도와 전투 화면 그리기
  12-sound, 12b-tutorial      효과음·배경 음악, 튜토리얼
  13-main                     처음 화면·설정·시작
build.mjs           → dist/index.html(단독 실행), dist/artifact.html, docs/index.html(GitHub Pages)
tools/              Playwright 시험
```

## 만들기

```
node build.mjs
```

## 시험

Playwright(크로미움)가 필요합니다. 화면 사진은 `shots/`(또는 `SHOT_DIR`)에 저장됩니다.

| 명령 | 내용 |
|---|---|
| `node tools/t1.mjs` | PC 화면 흐름(내정·출진·전투) |
| `node tools/t2.mjs` | 휴대폰 + 신무장 |
| `node tools/t3.mjs` | 장수로 플레이 |
| `node tools/t4.mjs` | 일기토 |
| `node tools/t5.mjs` | 역사 사건 하나씩 |
| `node tools/t10.mjs` | 시나리오 화면, 적벽 수전 |
| `node tools/t11.mjs` | 술집·의형제·혼인·임무·원군·진형 |
| `node tools/t13.mjs` | 먼 길 이동·수송 |
| `node tools/t17.mjs` | 적이 쳐들어왔을 때 실제 클릭으로 방어 |
| `node tools/t18.mjs` | 협공 출진 |
| `node tools/t20.mjs [phone]` | 튜토리얼을 실제 클릭으로 끝까지 |
| `node tools/audit.mjs 190 조조 120 1` | 장기 진행 불변식 점검(시나리오·인물·달·위임) |
| `node tools/hist.mjs 3 72 공융 1 190` | 역사 흐름 측정 |
| `node tools/shots.mjs` | PC·태블릿·휴대폰 화면 모음 |

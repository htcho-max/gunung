# 군웅할거

190년 반동탁 연합에서 시작하는 삼국 시대 턴제 전략 게임. HTML 한 파일, 그림·소리는 모두 코드로 만듦.

- 군주로 시작 / 장수로 시작(재야·사관·하야·거병·독립) / 신무장 만들기
- 내정(개간·상업·치안·성벽·징병·훈련), 인사(탐색·등용·포상), 외교(친선·3년 동맹), 계략(이간)
- 헥스 전투: 보병·기병·궁병, 화계(바람 따라 번짐)·혼란, 일기토, 본성 점령, 30일 제한, 포로 처분

## 만들기
`node build.mjs` → `dist/index.html`(독립 실행), `dist/artifact.html`(아티팩트용)

## 시험
`node tools/sim.mjs 120 유비` (AI끼리 10년), `tools/t1.mjs`(PC 화면), `t2.mjs`(휴대폰·신무장), `t3.mjs`(장수 플레이), `t4.mjs`(일기토)
